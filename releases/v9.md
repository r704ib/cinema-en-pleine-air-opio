# v9 — 2026-07-26

Migration de l'hébergement vers Firebase Hosting + nouveau nom de domaine.

## Changements

- **Nouveau domaine officiel** : le site est maintenant accessible à l'adresse
  **https://cinema-en-pleine-air-opio.oria-events.fr** (nom de domaine
  `oria-events.fr` acheté chez OVH).
- **Hébergement migré vers Firebase Hosting** (auparavant Netlify). Le site est
  désormais servi directement par Firebase, au même endroit que la base de
  données et les emails — un fournisseur en moins à gérer, et plus de limite
  de nombre de déploiements par mois.
- **Redirection automatique** mise en place sur l'ancienne adresse
  (`cinema-en-pleine-air-opio.netlify.app`) : tout lien déjà diffusé (affiches,
  SMS, réseaux sociaux) continue de fonctionner et renvoie vers la nouvelle
  adresse, sans rien casser.
- **Lien d'annulation dans les emails** mis à jour pour pointer vers le nouveau
  domaine (`SITE_URL` dans les Cloud Functions).

## Technique

- Ajout du bloc `hosting` dans `firebase.json` (sert le dossier `public/`).
- Déploiement initial sur Firebase Hosting, vérifié (contenu identique, codes
  HTTP 200) avant bascule.
- Sous-domaine `cinema-en-pleine-air-opio.oria-events.fr` connecté via un
  enregistrement CNAME chez OVH, pointant vers
  `cinema-en-pleine-air-opi-ac81e.web.app`. Certificat HTTPS généré et vérifié
  automatiquement par Firebase.
- `netlify.toml` : ajout d'une redirection 301 (`/*` → nouveau domaine),
  Netlify n'héberge plus de contenu, seulement la redirection.
- `functions/email-content.js` : `SITE_URL` mis à jour + test associé corrigé.
- Aucun changement de fonctionnement métier : réservations, jauge, emails,
  annulation inchangés pour les visiteurs.

## À savoir pour la suite

- Les déploiements du site passent désormais par `firebase deploy --only
  hosting` (au lieu du déploiement automatique GitHub → Netlify).
- L'adresse d'expéditeur des emails (Brevo) n'a pas encore été mise à jour pour
  utiliser le nouveau domaine — étape possible plus tard, non urgente.
